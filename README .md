## ⚡ 1-Minute GitHub Setup Guide

Follow these simple steps to push this project to your GitHub account and activate your permanent link:

### Step 1: Create a New GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Name your repository (e.g. `scam-shield-ai`).
3. Set visibility to **Public** and leave "Add README" **unchecked**.
4. Click **Create repository**.

### Step 2: Push Your Code
Open your terminal inside this project directory (`/home/megha/.gemini/antigravity/scratch/scam-shield-ai`) and run:
```bash
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/scam-shield-ai.git
git branch -M main
git push -u origin main
```

### Step 3: Activate GitHub Pages (Automatic or 1-Click)
1. On your GitHub repository page, go to **Settings > Pages** (in the left sidebar).
2. Under **Build and deployment > Source**:
   - Select **GitHub Actions** (the pre-configured `.github/workflows/pages.yml` will deploy it automatically!), OR
   - Select **Deploy from a branch** > branch: `main` > folder: `/docs` (or `/ (root)`).
3. Click **Save**.
4. Within 60 seconds, your permanent live link will be live at:
   `https://<YOUR-GITHUB-USERNAME>.github.io/scam-shield-ai/`

- **🎙️ Multilingual Voice AI Narrator**: Speaks verdicts out loud in 6 languages (English, हिन्दी, Español, Français, العربية, Deutsch) with speech-to-text dictation and real-time audio visualizer.

- **📝 "Paste Your Problem" — AI Incident Solver**: Natural language narrative analyzer that calculates loss severity, extracts suspects, and produces immediate recovery action plans.
- **🆘 "Already Scammed?" — Victim Recovery & Complaint Generator**: Step-by-step **Golden Hour protocol** to freeze scammer accounts via 1930, plus an automated **Cyber Crime Police Complaint Letter Generator** (IT Act Sec 66C/66D & BNS 318).
- **📞 Direct National Helplines (Call & Email)**: Direct 1-tap calling and pre-formatted complaint emails for India (1930), USA (1-800-CALL-FBI), UK (0300 123 2040), Canada, Australia, and UAE.
- **📊 Precise Component Risk Breakdown**: Granular floating-point probability meters for visual tampering, bank reference validity, urgency pressure, and carrier routing risk.
- **✨ 10 Ready-to-Test Demo Models**: 1-click presets for instant testing with zero typing.
